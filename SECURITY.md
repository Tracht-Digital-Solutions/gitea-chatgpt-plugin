# Sicherheitslücken melden / Reporting vulnerabilities

Bitte keine Tokens, private Repositoryinhalte oder ausnutzbare Details in öffentlichen Issues veröffentlichen. Verwenden Sie nach Möglichkeit [GitHub Private Vulnerability Reporting](https://github.com/Tracht-Digital-Solutions/gitea-chatgpt-plugin/security/advisories/new). Falls diese Funktion nicht verfügbar ist, melden Sie zunächst ohne technische Exploitdetails, dass ein privater Kontakt benötigt wird.

Please use GitHub private vulnerability reporting where enabled. Never include credentials or private repository data in public issues. If private reporting is unavailable, request a private contact without disclosing exploit details.

Unterstützte Version / Supported version: aktuelle 0.1.x-Entwicklungslinie. Keine SLA-Zusage. Sicherheitsmodell: [docs/SECURITY.md](docs/SECURITY.md).
