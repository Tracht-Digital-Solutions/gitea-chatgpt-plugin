# Step-by-step installation

Use the complete [source installation and configuration guide](INSTALLATION.md).

Run `node scripts/install.mjs --init`, edit `.env`, run `node scripts/install.mjs --check`, then `node scripts/install.mjs --start`. Verify HTTPS/OAuth and install the generated connection in ChatGPT. Settings are changed outside ChatGPT; no GitHub releases or image downloads are required.
